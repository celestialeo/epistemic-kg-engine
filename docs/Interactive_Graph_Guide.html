Topics and source versions

Topic means an input document or chapter. Source graph version means one saved pipeline run for that input. Its run name and ID identify the exact graph behind learning results.

All Topics includes one latest version per input topic. It shows an aggregate plus topic breakdowns. Exactly matching relationships count once: here two source occurrences represent one unique relationship.

Matching requires the same recorded endpoint meaning, direction and relation fields, including conditions. No synonym matching is inferred. Topic rows may overlap: do not add them to calculate the aggregate.

Choose a specific topic to select an older version. History retains earlier quizzes and labels them. Resuming a quiz explicitly selects its original source version.

Start, answer and resume a quiz

  1. Choose a student, quiz source, and optionally a starting concept.
  2. Click Start quiz and confirm the student. Questions skip green facts and prioritize gaps. Yellow becomes green only after a full-relationship demonstration without help.
  3. Type and submit an answer. A hint or reveal marks later answers as assisted. A correct short answer can score 100% while the full relationship stays yellow.
  4. Use Next question. Enable review to revisit independently known facts.

Each quiz belongs to one student and source run. In All Topics, exactly matching evidence avoids retesting known overlapping facts. A quiz never mixes source versions.

Saved quizzes offer Resume. Pending grading keeps the submitted answer and original request ID; use Retry pending request after the model recovers. Green stays earned across quizzes and restarts. Failed question drafts offer Try another concept. Failed hints show no answer; Reveal can use a display-checked saved answer, labelled Saved validated answer. Help errors do not erase grades. Unsubmitted text is not a durable answer.

Read and explore the graph

Drag, zoom, search, or use Fit graph and Show all. Distance and position are layout choices, not scores.

Student colors: green independent; amber partial or assisted; red incorrect or not demonstrated; gray unassessed. A concept circle is green only when all its connected facts are green. Mixed known and unknown links make it yellow. Counts distinguish states sharing a color.

In source exploration, blue means document and orange means background. In class view, brighter and thicker relationships mean more students independently know them, using the full roster.

Comparison does not grade a student. All Topics retains every relationship's source records; open one source for statement comparison.

Read the class overview

Coverage averages include every roster member. Answer scores include only students with measurements; n shows the sample size. Each student has equal weight.

Strengths show independent evidence. Difficulties separate partial, incorrect and not-demonstrated judgments from assisted successes. These are observed patterns, not diagnoses.

Click a card for details within Class Overview. Back to Class returns; Quiz This Student carries the context to Quiz. Miniatures preview up to 30 concepts and 60 links; metrics use the full scope.

Review results and correct grading

Use Inspect answers. Expand expected-answer and evidence details, choose a corrected mark per requested fact, write feedback and a reason, then save.

Question grading and graph matching are separate. If matching is unresolved, the question grade is saved and relationship progress stays unchanged. Use Retry graph matching here; it does not create another grade.

Original grading and corrections remain stored. Corrections respect the assessed scope: a component question cannot award full mastery, and assisted answers remain assisted.

Older sessions remain available. Independent mastery transfers across exact, unambiguous semantic matches with provenance. Answer scores are not copied. Correcting all invalid supporting awards can revoke green.

Understand learning metrics

MetricMeaning and denominator
Known without helpIndependently correct unique relationships / all unique relationships in scope.
CheckedResolved relationship assessments / all unique relationships. Unresolved matching does not add coverage.
Answer performanceMean latest answer per distinct session/question. Revisions count once. Assisted scores are also reported separately.
Connected understandingMastered concepts in the largest undirected mastered component / all mastered endpoints.
ConcentrationShares of independently known facts across graph communities (HHI). Near 1 means concentrated.

Coverage retains independently earned green across later attempts. Scores still reflect each answer; professor corrections can invalidate supporting credit. Different questions can test the same fact; answer performance and unique-fact coverage measure different things.

Expand Advanced learning metrics and progress for source-specific trends, exact values and graph communities. Separate versions are never joined into a fabricated trend. Definitions remain available at the bottom.

Inspect a saved pipeline run

Run Insights shows the selected saved graph, extraction and validation records, and available quality measurements. All Topics adds aggregate graph counts and a source breakdown with per-run inspection.

Expand Review background facts for quizzes to inspect generated claims and record an approval or revocation with a reason. Approval is specific to this graph version. Unapproved background facts cannot be used in quizzes.

Reconstruction compares rebuilt text with the original. It measures pipeline fidelity, not student learning or independently verified truth. Missing measurements stay unavailable.

Expand validation records, original/reconstructed text or advanced diagnostics when needed. Timings are duration, not quality. No mixed-version quality score is fabricated.

Records persist in outputs/professor/students.sqlite3. Viewing saved graphs needs no extraction. New quizzes, grading and statement matching need the configured model service. This is a local professor-operated app.
