A supervised classifier learns a mapping from inputs to labels using labeled training examples. During training, an optimization algorithm adjusts the model parameters to reduce a loss function. The loss function measures disagreement between the model's predictions and the training labels, providing a signal for these parameter updates.

A validation set contains examples that are separate from the training set. Developers use validation results to select model settings before evaluating the chosen model on a held-out test set. Good performance on the training examples alone does not guarantee good performance on previously unseen examples from the intended application.

Regularization can reduce overfitting by limiting a model's tendency to fit incidental details of the training data. After training, quantization represents model parameters with fewer bits and can reduce the memory needed to store them. Lower numerical precision can also reduce prediction accuracy, so the quantized model should be evaluated again.
