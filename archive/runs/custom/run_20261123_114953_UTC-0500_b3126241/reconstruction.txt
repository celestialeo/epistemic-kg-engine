An artificial intelligence tutor answers questions about a collection of course documents. A tutor uses a language model to generate explanations. Fluent wording does not guarantee factual accuracy of the generated explanations. During training, a language model adjusts parameters of the language model using examples from a training dataset. A validation dataset supports model selection and choice of training settings. After those choices have been made, a held out test dataset measures performance. Datasets must be separated carefully if passages from the same source appear in both training and testing to avoid bias. Dataset size does not alone establish dataset quality.

The tutors language model employs a decoder only transformer to process text. A tokenizer divides an input passage into tokens. An embedding layer maps these tokens to numerical vectors. Positional information helps the transformer distinguish sequences containing the same tokens in different orders. Self attention combines information from token representations. A causal attention mask prevents the model from attending to later positions when predicting the next token. Attention connects information across a passage, though models have a finite context window that limits the text available in a single request. Restrictions apply to both training and generation phases. Attention weights do not validate the truth of associated claims.

The learning rate controls the size of updates of those updates; it can makes_unstable training stability that is too large and can slows improvement speed that is very small. A tutor employs weight quantization after training to store model parameters with fewer bits, thereby reducing the memory required to store those parameters. However, an aggressive reduction in precision may degrade answer quality. The tutor also employs retrieval augmented generation after training for different purposes; when the tutor answers a question, this technique supplies relevant course passages. A retrieval encoder maps questions and document passages into embeddings, which similarity search uses to select candidate passages from an index. These selected passages are added to the language models context. Updating the index enables making revised course material available without retraining the language model. Retrieval itself does not change the models parameters. Additionally, a highly ranked passage can still be irrelevant content.

The evaluation distinguishes from the quality of the generated answer. Retrieval precision measures precision of among returned passages and shows that the tutor use of retrieved evidence correctly does not alone indicate the state. Conversely, retrieval recall shows the tutor use of retrieved evidence correctly alone. An answer can cite with real passage and makes that the passage does not support a claim. The tutor is evaluated for support from the supplied documents and appropriate handling of uncertainty. The tutor should identify when two course passages disagree but does not merge disagreement between two course passages into an unsupported conclusion. Furthermore, failure to retrieve supporting evidence does not establish or prove that the proposed claim is false.
