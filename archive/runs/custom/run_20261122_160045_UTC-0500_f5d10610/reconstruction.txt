An artificial intelligence tutor answers questions about a collection of course documents. A tutor uses a language model to generate explanations. Fluent wording does not guarantee factual accuracy for the tutor's explanations. The language model adjusts parameters using examples from a training dataset. A separate validation dataset supports model selection and the choice of training settings. A held out test dataset measures performance after those choices have been made. Measured performance can overstate model ability to handle unfamiliar material if passages from the same source appear in both training and testing. Measured performance can also overstate the capability of models ability to handle unfamiliar material under the same condition. Dataset size does not establish dataset quality alone.

The tutors language model employs a decoder only transformer structure to process text. A tokenizer divides an input passage into tokens, which are then mapped by an embedding layer into numerical vectors. Positional information helps the transformer distinguish sequences containing the same tokens in different orders. Self attention combines information from token representations within the attention layer. A causal attention mask prevents the model from attending to later positions when predicting the next token, a restriction that applies during both training and generation. Attention can connect information across a passage, though models with a finite context window limit the amount of text available in a single request. Attention weights support evidence for the truth of associated claims.

Training compares models predicted token probabilities with next tokens in the training examples. A loss function quantifies error metric of prediction error. Backpropagation computes gradients, which are used by an optimizer to update model parameters. The learning rate controls size of updates of those updates; it can make unstable training stability when learning rate is too large and can slows improvement speed when learning rate is very small. Overfitting occurs when improved training performance fails to translate into performance on unseen examples. Dropout randomly disables some activations during training. Ordinary inference employs trained network for operation without that random disabling. Early stopping uses metric to guide action using validation performance to decide when to end training and does not use held out test results for selecting a stopping point.

The tutor employs weight quantization after training to store model parameters with fewer bits, thereby reducing the memory required to store those parameters. However, an aggressive reduction in precision may degrade answer quality. The tutor also employs retrieval augmented generation after training for different purposes; when the tutor answers a question, this technique supplies relevant course passages. A retrieval encoder maps inputs of the question and document passages into embeddings, which similarity search uses to select candidate passages from an index. These selected passages are added to language models context. A document index enables access to revised course material via updating and can allow avoidance of language model retraining for making revised course material available. Retrieval does not itself change models parameters. Even a highly ranked passage can still be irrelevant, outdated, or incorrect.
